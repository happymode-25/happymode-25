## CURRENT BUILD

### obsidian-os

A Windows-feel Linux, hardened by default. Custom distribution whose desktop
mirrors Windows 11 conventions, paired with a unified Bash/PowerShell shell.

- five flavors, each a single package list: `daily` `developer` `pentester` `server` `ghost`
- CIS Debian Benchmark hardening, attested at boot
- hybrid BIOS + UEFI ISO built by mmdebstrap -> packages -> overlays -> squashfs
- boot test asserts on a marker stock Debian cannot emit

> **Status, stated plainly:** the desktop does not exist yet. No window manager,
> no panel, no applications. Treat the Windows 11 look as a Phase 2 deliverable.
> An earlier claim of Phase 0 completion was wrong and is documented with
> evidence in the repo.

### egress-broker

Fail-closed egress proxy for an AI agent. One file, Python 3.9+ standard
library, no dependencies.

- DNS pinning, so resolution cannot drift under you
- threshold alerting, trips before a leak becomes a breach
- per-client policy scoping
- hash-chained, tamper-evident sqlite audit log
